Painel de checkouts

Na Hotmart, abra Produtos → Meus produtos → Links de divulgação → Página de pagamento, copie o endereço de cada produto e cole abaixo. Confirme o ID correspondente antes de salvar. Clique em Baixar checkouts.js. Depois envie somente esse arquivo ao repositório do site, substituindo o anterior. Você não precisa editar o index.html.

Importante: Este painel gera apenas um arquivo no seu navegador. Os links não são enviados a ninguém. Não inclua senhas, tokens de API ou dados de clientes. O arquivo checkouts.js será público, como qualquer link de venda.

Você pode cadastrar apenas 1, 3 ou 12 produtos: os que ficarem vazios mostrarão a mensagem de checkout indisponível, sem gerar cobrança. São aceitos somente links oficiais https://pay.hotmart.com/..., https://go.hotmart.com/... ou https://hotm.art/.... Confira se cada link corresponde ao ID do produto indicado. Nunca insira senhas ou tokens.
